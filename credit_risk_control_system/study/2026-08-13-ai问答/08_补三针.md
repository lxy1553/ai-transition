### 第 1 针：真调 DeepSeek LLM

在 `llm_client.py` 里加了 `DeepSeekLLM` 真实实现 + `create_llm()` 工厂：

```python
class DeepSeekLLM(LLMClient):
    # 真发 HTTP 请求到 DeepSeek，chat 和 chat_json 两个方法
    # JSON mode 用 response_format={"type": "json_object"}

def create_llm(catalog=None) -> LLMClient:
    api_key = os.environ.get("DEEPSEEK_API_KEY", "").strip()
    if api_key:
        return DeepSeekLLM(api_key)   # 有 Key 真调
    return MockLLM(catalog)            # 没 Key 降级 Mock
```

关键：设 `DEEPSEEK_API_KEY` 自动切真 LLM，没 Key 用 Mock，代码不用改。
