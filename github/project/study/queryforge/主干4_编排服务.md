## 三问

## 一、run_query 核心（text2sql.py 逐段）

### ① 缓存判断（多轮跳过）

```python
async def run_query(req):
    # 缓存仅用于"无历史"请求。多轮答案依赖上下文，不能按 (db, 问题) 做键
    use_cache = not req.history   # ★ 有历史就不缓存（防串答案）
```

**大白话**：单轮可缓存（同问同答）；多轮跳过（答案依赖上下文，缓存会错）。

### ② 两级缓存短路

```python
    if use_cache:
        # 精确缓存（Redis：同问题命中）
        cached = await get_cached(req.db_id, req.question)
        if cached:
            return QueryResponse(**cached, from_cache=True)   # ★ 命中直接返回，不调 LLM

        # 语义近似缓存（pgvector：同义问题命中）
        sem = await get_semantic_cached(req.db_id, req.question)
        if sem:
            await set_cached(req.db_id, req.question, sem)   # 回填精确缓存
            return QueryResponse(**sem, from_cache=True)
```

**大白话**：先精确缓存（同问题）→ 再语义缓存（同义问题）→ 命中就返回，**跳过整条 LLM 链路**。

### ③ 调 LangGraph

```python
    graph = await get_graph()
    init_state = {
        "question": req.question, "db_id": req.db_id,
        "attempt": 0, "history": history,   # 多轮上下文
    }
    thread_id = req.thread_id or f"oneshot-{uuid.uuid4().hex}"   # 单轮用临时 id
    config = {"recursion_limit": 25, "configurable": {"thread_id": thread_id}}
    final = await graph.ainvoke(init_state, config=config)   # 走完整链路
```

### ④ 错误处理（两类失败区分）

```python
    except Exception as e:
        # 图抛异常（限流/超时/熔断/未知bug）→ 分类映射 429/503/500
        err = classify(e)   # ★ 错误分类
        raise err from e
    # 注意区分：
    #   - 图抛异常 = 系统错误（429/503/500）
    #   - 图正常返回但 success=false = SQL 多次自纠错仍失败（返回 QueryResponse）
```

**大白话**：两类失败分开——系统挂了（限流/超时）报 429/503；SQL 没生成对返回 success=false。**正是之前学的"系统错误vs 安全阻断"**。

### ⑤ 组装响应 + 写缓存

```python
    resp = QueryResponse(
        question=req.question, db_id=req.db_id,
        sql=final.get("sql", ""), success=bool(final.get("success")),
        answer=final.get("answer", ""), language=final.get("language", "zh"),
        columns=result.get("columns", []), rows=result.get("rows", []),
        row_count=result.get("row_count", 0),
        attempts=final.get("attempt", 0), error=final.get("error"),
    )

    # 只缓存成功结果 + 单轮
    if resp.success and use_cache:
        await set_cached(req.db_id, req.question, payload)          # 精确缓存
        await set_semantic_cached(req.db_id, req.question, payload) # 语义缓存
    return resp
```

**大白话**：把图的 final 状态组装成 QueryResponse（含 sql/success/answer/rows），成功结果写缓存。

## 二、API 端点（query.py）

```python
@router.post("/query", response_model=QueryResponse)
@limiter.shared_limit(settings.RATE_LIMIT_QUERY_GLOBAL, scope="query-global")  # 全局限流
@limiter.limit(settings.RATE_LIMIT_QUERY)        # 每用户限流
async def query(request, body, user=Depends(get_optional_user)):
    if not settings.PUBLIC_QUERY_ENABLED and user is None:
        raise HTTPException(401, "未登录")        # 鉴权
    async with query_inflight_slot():             # 在途并发控制
        return await run_query(body)
```

**大白话**：POST /query，三层防护（全局限流 + 每用户限流 + 鉴权）+ 在途并发控制，然后调 run_query。

## 三、完整请求流程（一图）

```
POST /query
  │  限流 + 鉴权 + 在途并发
  ▼
run_query
  │  有历史？→ 跳过缓存
  │  无历史？
  │    ├─ Redis 精确缓存？命中 → 返回（不调 LLM）
  │    ├─ pgvector 语义缓存？命中 → 返回
  │    └─ 未命中 → 走 LangGraph
  ▼
LangGraph（detect → ... → generate → validate → execute → format）
  │  成功 → 写缓存（精确 + 语义）
  │  图抛异常 → classify → 429/503/500
  ▼
返回 QueryResponse（success + sql + answer + rows）
```

## 四、对照 ai_assistant 的改造动作

```python
# 现在：Python 函数

# 改造 1：FastAPI 端点 + 鉴权
@app.post("/query")
async def query(request, user=Depends(get_user)):
    if not permission(user): raise HTTPException(401)
    return await run_query(request)

# 改造 2：加缓存（先 Redis 精确缓存）
async def run_query(req):
    cached = await cache.get(req.question)
    if cached: return cached          # 命中不调 LLM
    answer = await pipeline.ask(req.question)
    if answer.success:                # 只缓存成功
        await cache.set(req.question, answer)
    return answer
```

**改造要点**：pipeline.ask → FastAPI + 缓存 + 限流 + 鉴权。

## 五、小结

| 学到 | 一句话 |
|------|--------|
| 缓存短路 | 命中跳过 LLM（省钱）|
| 多轮跳过缓存 | 答案依赖上下文 |
| 两类失败 | 系统错误（429/503）vs 业务失败（success=false）|
| 只缓存成功 | 失败不缓存，下次重试 |
| 写缓存 | 精确 + 语义两层 |
| API 防护 | 限流 + 鉴权 + 在途并发 |

> **核心心法**：run_query = 缓存短路 + LangGraph + 写缓存 + 错误分类。你的 ai_assistant 最该加 **API 层 + 缓存**——相同问题不重复烧 LLM，且能做成网页产品。
