## 三问（先想清楚再读代码）

- **Q1 解决什么问题**：记住"哪些查询模式成功过"，下次复用，避免重复犯错
- **Q2 数据流哪一环**：作为 ToolContext 的一部分，每个工具调用都带着记忆
- **Q3 删掉会怎样**：每次冷启动，同样的错反复犯 → 效果上不去

## 核心骨架（待填充）

```python
class AgentMemory(ABC):
    # 存：记录一次成功的工具用法
    async save_tool_usage(question, tool_name, args, context, success): ...
    # 查：找类似的历史成功用法
    async search_similar_usage(question, context, limit, similarity_threshold): ...
```

### 工具（LLM 可主动调）
```python
SaveQuestionToolArgsTool       # 记住：这个问题 + 这个工具 + 参数 成功了
SearchSavedCorrectToolUsesTool # 找类似问题之前怎么成功的
```

### 实现
- `DemoAgentMemory`：零依赖，Jaccard/difflib 相似度（阶段1 用过）
- `ChromaAgentMemory`：向量库，语义相似度

## 关键洞察

**这是"训练式 RAG"**——不是每次现查，而是记住成功的 query→SQL 映射。下次用户问类似问题，先搜记忆，命中就复用之前的 SQL 模式。

## 对照 ai_assistant

你的 RAG 是"静态检索文档" → 加"成功查询记忆"（用户问过且查对的 SQL 存下来）。

> 核心心法：Vanna 记住成功查询模式，下次复用——训练式 RAG 的精髓。
