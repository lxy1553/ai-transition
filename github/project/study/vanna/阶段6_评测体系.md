# Vanna 阶段 6：评测体系（系统化评估 Agent）

> **目标**：理解怎么系统化评估一个 NL2SQL/Agent——不是"我觉得可以"，而是"有数字、有 bad case、可回归"。
> 看 evaluation 框架（dataset/evaluators/runner/report），理解评测的完整流程。
>
> **核心**：评测 = 测试集 + 评估器 + 跑分 + 报告。你的 `eval_qa.py` 该长成这样子。

## 三问

- **Q1 解决什么问题**：Agent 效果可量化——准确率、bad case、回归测试
- **Q2 数据流哪一环**：独立于 Agent 循环——离线跑评测集，衡量 Agent 好坏
- **Q3 删掉会怎样**：无法量化效果，面试说不出数字，改坏不知道

## 一、评测整体流程（四件套）

```
① 测试集（dataset.py）：一堆用例，每个含"期望结果"
  → 用户问题 + 期望（调哪些工具 / 答案含什么）
  ↓
② 跑 Agent（runner.py）：每个用例跑一遍 Agent
  → 记录 Agent 做了什么（调的工具、最终答案、耗时）
  ↓
③ 评估器（evaluators.py）：用"期望"对比"实际"
  → 判断：通过/失败 + 分数 + 原因
  ↓
④ 报告（report.py）：汇总所有用例结果
  → 准确率、bad case 列表、按维度分组
```

**大白话**：先出题（测试集）→ 让 Agent 做题（runner）→ 批改（evaluator）→ 出成绩单（report）。

## 二、测试集：TestCase 和 ExpectedOutcome（`base.py`）

```python
# 期望结果——定义"Agent 应该怎么做"
class ExpectedOutcome(BaseModel):
    tools_called: Optional[List[str]] = None          # 应该调哪些工具
    tools_not_called: Optional[List[str]] = None      # 不该调哪些工具
    final_answer_contains: Optional[List[str]] = None # 答案应包含哪些关键词
    final_answer_not_contains: Optional[List[str]] = None # 答案不该包含什么
    min_components: Optional[int] = None              # 最少返回几个 UI 组件
    max_execution_time_ms: Optional[float] = None     # 最长耗时

# 一个测试用例
class TestCase(BaseModel):
    id: str                      # 用例 ID
    user: User                   # 用户上下文
    message: str                 # 发给 Agent 的问题
    conversation_id: Optional[str] = None   # 多轮测试用
    expected_outcome: Optional[ExpectedOutcome] = None   # 期望结果
    metadata: Dict = {}          # 附加信息（分类用）
```

**大白话**：测试集 = 一组"问题 + 期望"。期望可以指定"该调哪些工具""答案含什么"——这就是怎么判断 Agent 做对没。

**例子（信贷场景）**：
```python
TestCase(
    id="tc_001",
    user=User(id="u_1001", group_memberships=["analyst"]),
    message="上个月逾期率是多少",
    expected_outcome=ExpectedOutcome(
        tools_called=["run_sql"],                    # 应该调 run_sql
        final_answer_contains=["3.2%"],              # 答案应含 3.2%
    ),
)

TestCase(
    id="tc_002",
    user=User(id="u_1002", group_memberships=["guest"]),
    message="查一下逾期率",
    expected_outcome=ExpectedOutcome(
        tools_not_called=["run_sql"],                # 无权限不该调
        final_answer_contains=["无权限"],            # 应拒绝
    ),
)
```

### 真实评估器（`evaluators.py`）—— 4 种

```python
# ① 轨迹评估器：检查工具调用轨迹
class TrajectoryEvaluator(Evaluator):
    """检查 Agent 调了哪些工具（对不对）"""
    async def evaluate(self, test_case, agent_result):
        called = agent_result.get_tool_names_called()
        expected = test_case.expected_outcome.tools_called
        # 该调的调了？不该调的没调？
        missing = set(expected or []) - set(called)
        passed = not missing and not unexpected
        return EvaluationResult(passed=passed, score=..., reasoning=...)

# ② 输出评估器：检查最终答案
class OutputEvaluator(Evaluator):
    """检查最终答案是否含期望关键词"""
    async def evaluate(self, test_case, agent_result):
        answer = agent_result.get_final_answer()
        contains = test_case.expected_outcome.final_answer_contains
        # 答案含期望关键词吗？
        passed = all(kw in answer for kw in contains or [])
        return EvaluationResult(passed=passed, score=..., reasoning=...)

# ③ LLM 当裁判：用 LLM 判断答案质量
class LLMAsJudgeEvaluator(Evaluator):
    """用另一个 LLM 当裁判，评估回答质量"""
    async def evaluate(self, test_case, agent_result):
        # 把答案给 LLM，让它评分
        verdict = await judge_llm.rate(test_case.message, agent_result.get_final_answer())
        return EvaluationResult(passed=verdict.passed, score=verdict.score, reasoning=...)

# ④ 效率评估器：检查耗时/token
class EfficiencyEvaluator(Evaluator):
    """检查耗时是否超标"""
    async def evaluate(self, test_case, agent_result):
        max_time = test_case.expected_outcome.max_execution_time_ms
        passed = agent_result.execution_time_ms <= max_time
        return EvaluationResult(passed=passed, score=..., reasoning=...)
```

**大白话**：4 种评估器 = 4 种"批改方式"：
- 轨迹：调对工具了吗？
- 输出：答案对吗？（含关键词）
- LLM 裁判：让另一个 LLM 评质量
- 效率：快吗？

**组合使用**：一个用例可以多个评估器一起判（轨迹 + 输出 + 效率），全过才 PASS。

## 五、跑分：EvaluationRunner（`runner.py`）

```python
class EvaluationRunner:
    """跑评测——对每个用例跑 Agent + 评估"""

    async def run_evaluation(self, test_cases, agent, evaluators) -> List[TestCaseResult]:
        results = []
        for test_case in test_cases:
            # ① 跑 Agent
            agent_result = await self._run_agent(agent, test_case)
            # ② 逐个评估器批改
            evaluations = []
            for evaluator in evaluators:
                eval_result = await evaluator.evaluate(test_case, agent_result)
                evaluations.append(eval_result)
            # ③ 汇总
            results.append(TestCaseResult(
                test_case=test_case, agent_result=agent_result,
                evaluations=evaluations, execution_time_ms=...,
            ))
        return results
```

**大白话**：runner = "监考老师"——对每个用例：跑 Agent → 用所有评估器批改 → 汇总结果。

## 六、结果判定（`base.py`）

```python
class TestCaseResult:
    """一个用例的完整结果"""
    def overall_passed(self) -> bool:
        """所有评估器都过 = PASS"""
        return all(e.passed for e in self.evaluations)

    def overall_score(self) -> float:
        """平均分数"""
        if not self.evaluations: return 0.0
        return sum(e.score for e in self.evaluations) / len(self.evaluations)
```

**大白话**：一个用例 = 所有评估器都过才算对；分数 = 各评估器平均。

## 七、对照 ai_assistant（你的 eval_qa.py 该升级成这个）

你的 `eval_qa.py` 已有雏形（55 条评测集 + 意图/指标/行为准确率）。对照 Vanna 评测框架：

```python
# 你现在的 eval_qa.py（雏形）
report = evaluate(pipeline, cases)   # 简单跑 + 算准确率
#   只有"行为判定"一种评估

# 升级成 Vanna 式（多评估器 + 结构化）
evaluators = [
    TrajectoryEvaluator(),    # 检查工具调用轨迹
    OutputEvaluator(),        # 检查答案关键词
    EfficiencyEvaluator(),    # 检查耗时
]
runner = EvaluationRunner()
results = await runner.run_evaluation(test_cases, pipeline, evaluators)

# 汇总报告
accuracy = sum(r.overall_passed() for r in results) / len(results)
bad_cases = [r for r in results if not r.overall_passed()]
```

**改造要点**：
1. 评测集：加 `ExpectedOutcome`（工具/关键词/耗时）
2. 评估器：从"行为判定"升级成多个（轨迹/输出/效率）
3. 报告：结构化（准确率 + bad case 列表 + 按维度）
4. 回归：每次改动重跑，bad case 不增加 = 没改坏
